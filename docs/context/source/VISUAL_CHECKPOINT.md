## Cómo retomar con poco contexto

Leer primero este checkpoint y mirar la propuesta aprobada. Consultar Backups/HouseRuins/verification.md para conocer qué existe realmente. Abrir solo los scripts del sistema que se vaya a cambiar. El grafo en docs/context/graphify-out es un mapa semántico de este documento y sus decisiones; no es un índice de todo C# ni prueba de dependencias de código. Su manifest permite detectar si la nota cambió.

Directo para archivos conocidos; Serena para símbolos C# cuando haga falta; Unity para importación/compilación/Play; Graphify para este contexto o análisis de dependencias significativo; documentación externa solo si hay una duda concreta. No rehacer auditorías, recorrer todo Assets, indexar caches, instalar dependencias, modificar configuración de agentes/Git ni reejecutar pruebas de gameplay que no correspondan a los cambios futuros.
